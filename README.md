# Час у дорозі

PWA для водіїв: облік робочого часу.

- **Почати / Закінчити роботу** — одна велика кнопка, таймер іде наживо.
- **Перерва** — час перерви не входить у робочий час.
- Підсумки за **сьогодні, тиждень, місяць** (зміна після опівночі ділиться між днями).
- **Історія змін** з групуванням по днях; натисни на зміну, щоб виправити її чи видалити.
- **Експорт у CSV** (відкривається в Excel / Google Таблицях).
- Працює **офлайн**, ставиться на головний екран телефона.

Дані зберігаються лише на пристрої (localStorage).

## Запуск локально

```bash
npx serve .
```

Або будь-який статичний сервер. Для публікації підійде GitHub Pages / Netlify — збірка не потрібна.
